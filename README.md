## Собственный проект

Тема проекта: Оружия

Главный класс: Weapon

Почему этот объект нужен программе:

- Класс Weapon может хранить оружия героев из гильдии

Какие данные хранит объект:

- Имя оружия
- Тип оружия
- Урон оружия
- Прочность оружия

Какие значения задаются через конструктор:

- Имя
- тип
- урон

Какие значения можно задавать автоматически:

- Прочность

#### Какое значение я решил задавать автоматически и почему?

Значение Прочности задается автоматически при создании нового оружия. По умолчанию прочность равна 1, при этом минимальная прочность - 0.

#### Как проверили недопустимый урон:

Проверили через 2 условия:

- Отсекаем отрицательные значения чтобы не восстанавливать здоровье уроном
- Восстанавливаем здоровье до 0, если оно уходит в отрицательную зону

## Самостоятельная №2

#### Первая ошибка

public int Health { get; set; } - Нужно заменить 'set' на 'private set'

#### Вторая ошибка

value.Trim();

\_name = value;

.Trim() - не изменяет исходные данные а преобразует текст в конкретном месте. Так что правильная запись будет выглядеть так:

\_name = value.Trim();

#### Ответы на вопросы

- Чем отличается запрет внешней записи от проверки допустимого числа? Где проверяются здоровье при создании и его изменение?

Запрет - полностью запрещает изменять переменную на прямую, а проверка проверяет что хочет записать пользователь и если данные соответствует - записывает. При создании здоровье проверяется в конструкторе, а при изменении в методе TakeDamage().

- Как Name = name; связывает параметр конструктора, value и поле \_name?
  поле - свойство

Здесь name записывается в public поле Name, а Внутри поля Name запись идет в \_name через set().
